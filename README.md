# Taniya Vishwakarma — Static HTML Portfolio

This version converts the supplied Next.js + Tailwind portfolio template into a static HTML/CSS/JavaScript site while preserving the original template's light, spacious, card-based visual language.

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Main files
- `index.html` — complete single-page portfolio
- `styles.css` — responsive light theme
- `script.js` — mobile navigation, year and contact mailto handling
- `assets/profile.jpg` — supplied professional photograph
- `assets/` — template artwork/assets retained where useful

## Notes
- Company/project marks are presented as clean logo-style badges so the page remains self-contained and professional.
- Replace any badge with an official SVG/logo file if you have permission and want exact brand artwork.
- Update contact information directly in `index.html` if needed.
