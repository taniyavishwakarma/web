The bigger idea

Speed is a solved problem. Trust is the next frontier.

AI can generate a test case in seconds. Deciding whether that test case — or the agent, chatbot, or copilot it's testing — is truly trustworthy is still a human judgment call. That's the part I find most exciting about where QA is headed, and it's the part I'd love to spend my time on here.

From idea to shipped work

Three building blocks toward the Trust Score, in the first 90 days

A new practice doesn't start as a slide — it starts as three small, demoable pieces that later assemble into the scorecard. Click a tab.

A hallucination/guardrail rubric, run before the maker-checker step

SDET360.AI already has a creator → reviewer workflow. I'd bring the same checklist I use on AI-powered workflows at McKinsey — checking generated output for hallucination, missing edge cases, and consistency against the source requirement — as a lightweight pre-check that makes the human reviewer's job faster. This becomes the first metric that feeds the Trust Score.

Locator-resilience checks alongside the locator generator

A short Playwright harness that re-runs generated locators against intentionally-mutated DOM states (attribute renamed, element re-nested, class removed) and reports which ones would have needed self-healing. Turns "self-healing" into a number clients can watch improve, release over release — the scorecard's second metric.

Performance budgets as a CI/CD gate, not a post-release report

My JMeter work has mostly fed dashboards after the fact. I'd wire response-time and throughput thresholds into the same Jenkins/GitHub Actions pipeline SDET360.AI already plugs into, so a performance regression fails the build — the scorecard's third and most mature metric.

sketch — not production code
// Pre-check run on AI-generated test cases before reviewer sign-off
function guardrailScore(output: GeneratedCase) {
  const checks = [
    hallucinationFree(output),
    coversEdgeCases(output.acceptanceCriteria),
    matchesSourceStory(output.storyId),
    guardrailAdherence(output),
  ];
  return checks.filter(Boolean).length / checks.length; // feeds Trust Score
}
// Re-checks a generated locator against mutated DOM snapshots
import { test, expect } from '@playwright/test';

const mutations = ['renamed-attr', 're-nested', 'class-removed'];

for (const mutation of mutations) {
  test(`locator survives: ${mutation}`, async ({ page }) => {
    await page.goto(`/fixtures/checkout?mutate=${mutation}`);
    const submit = page.getByRole('button', { name: /place order/i });
    await expect(submit).toBeVisible({ timeout: 2_000 });
  });
}
